DMS · Document Management

Documents are archived in a clear structure and found by AI search, down to the page.

ECM+ captures, classifies, versions and retrieves every document under access permissions, retention rules and a complete audit trail.

Request a demoExplore the suite

01Overview

One archive for the whole organization

Every document is filed under a document type with its own index fields, in folders that carry their own access permissions.

Staff find documents by meaning or by field, open the exact page, and work on the file without leaving the suite.

02Capabilities

Key capabilities

  • AI search

    Finds documents by meaning as well as by exact words, and highlights matches down to the page. Voice search and search history are included.

  • Index fields filled by AI

    When a document is archived, AI reads the file and fills its index fields, such as text, numbers and dates, for staff to review.

  • Document types

    Each document type has its own index fields: text, number, date, dropdown, multi-select and checkbox.

  • Folder access permissions

    9 permission types per folder, from View and Print to “View without watermark”.

  • Version history

    Every file keeps its full version history, and any version can be restored or downloaded.

  • Retention rules

    Delete or notify actions run on schedule, with a log of every execution.

  • Locked documents

    A locked document opens only with a one-time verification code sent by email, SMS or WhatsApp. Its content stays hidden in search.

  • Reports

    The report designer adds a cover page, headers and footers, and exports to PDF, Word or Excel.

03How it works

How a document moves through the archive

  1. 01

    Capture

    Files arrive from devices, scanners, templates, Google Drive or OneDrive, or as voice and video notes.

  2. 02

    Index

    AI fills the document type’s index fields from the file, and staff confirm them before saving.

  3. 03

    Protect

    Folder permissions and locked documents control who sees each page, and the access trace code records every view and download.

  4. 04

    Find

    AI search finds documents by meaning and opens the matching page.

  5. 05

    Retain

    Retention rules delete documents or send notifications on schedule, and every action is logged.
