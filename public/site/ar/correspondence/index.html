CMS · نظام إدارة المراسلات

تُسجَّل كل مراسلة وتُحال وتُعتمد، مع سجل كامل لكل خطوة.

تسجّل منظومة ECM+ المراسلات الواردة والصادرة والداخلية بأرقام تسلسلية، وتحيلها إلى المختصين، وتوثّق كل خطوة حتى إغلاقها.

01نظرة عامة

ضبط المراسلات الرسمية في جميع مراحلها

تحمل كل مراسلة رقمًا تسلسليًا ومراجع خارجية وأطرافًا وأولوية ودرجة سرية وتاريخ استحقاق ووسومًا.

وتجري المراجعة والاعتماد قبل خروج أي مراسلة من المؤسسة، ويعرض مخطط المراسلة المسار الذي سلكته.

02القدرات

أبرز القدرات

  • 3 اتجاهات

    مراسلات واردة وصادرة وداخلية، بأرقام تسلسلية ومراجع خارجية.

  • الإحالة إلى أي جهة

    تُحال المراسلات إلى الموظفين أو المجموعات أو الإدارات أو الجهات الخارجية، بصفة «إلى» أو «نسخة» أو «نسخة مخفية».

  • تعليمات بأي صيغة

    تُرفق التعليمات نصًّا أو ملفًا أو ملاحظة صوتية أو مرئية.

  • المراجعة والاعتماد

    تُرسَل المراسلة للمراجعة، ثم تُعتمد أو تُعاد قبل إرسالها.

  • الإرسال الخارجي

    يطبع موظف الصادر المراسلة المعتمدة ويختمها ويرسلها.

  • مخطط المراسلة

    يعرض مخطط مرئي المسار الذي سلكته كل مراسلة، مع سجل لكل خطوة.

  • قواعد الإحالة

    تُحيل القواعد المراسلات تلقائيًا وفق المحفّز والشروط والمستلمين.

  • صندوق البريد

    يُربط Gmail أو Outlook أو أي بريد مؤسسي بالمنظومة، وتُحفظ الرسائل ضمن مراسلة أو في الأرشيف.

03آلية العمل

مسار المراسلة

  1. 01

    التسجيل

    تحصل المراسلة على رقم تسلسلي، وتُحدَّد أطرافها وتاريخ استحقاقها.

  2. 02

    الإحالة

    تُحال إلى الموظفين أو الإدارات المختصة مع التعليمات.

  3. 03

    المراجعة

    تُراجَع المراسلة الصادرة، ثم تُعتمد أو تُعاد.

  4. 04

    الإرسال

    يطبع موظف الصادر المراسلة المعتمدة ويختمها ويرسلها.

  5. 05

    الأرشفة

    تُغلق المراسلة وتُؤرشف مع سجلها الكامل.
